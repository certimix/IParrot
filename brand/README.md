# Marca IParrot

- Cor predominante: `#2D3691` (medida no fundo da logo original).
- `logo-icon.svg` / `icon-*.png` / `icon.ico`: ícone do app (papagaio branco sobre azul).
- `logo.svg`, `logo-white.svg`: papagaio + nome "IParrot" (o texto usa a fonte Nunito; para uso externo, converta o texto em curvas).
- `logo-mark-*.svg`: só o papagaio, sem fundo.
- `icon-foreground-1024.png`, `icon-square-1024.png`: bases dos ícones adaptativos do Android e do iOS.

O traçado foi vetorizado a partir do PNG enviado (735×551). Se existir o arquivo vetorial original da logo,
substitua `parrot-path.txt` por ele para ter as curvas exatas.

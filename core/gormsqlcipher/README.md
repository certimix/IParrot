# gormsqlcipher

Dialeto GORM para SQLite criptografado (SQLCipher).

Cópia sem alterações de `go/internal/gorm-sqlcipher` do projeto
[Berty](https://github.com/berty/berty) (tag v2.472.0), que por sua vez deriva de
`gorm.io/driver/sqlite` (MIT, © Jinzhu). O pacote original é `internal` no módulo
do Berty e por isso não pode ser importado diretamente — por isso está copiado aqui.
